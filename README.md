# InboxBuddy - AI Email Assistant

InboxBuddy is an AI-powered email assistant that helps users generate and manage email replies efficiently.

## Features
- AI-generated email replies
- Browser extension integration
- Spring Boot backend with AI API
- User-friendly frontend interface

## Tech Stack
- Spring Boot
- Spring AI
- React.js
- Browser Extension
- Gemini API

## Project Structure
backend – Spring Boot application
frontend – Web UI
extension – Browser extension for email integration

## How to Run

Backend
cd backend
mvn spring-boot:run

Frontend
cd frontend
npm install
npm start"# InboxBuddy"
